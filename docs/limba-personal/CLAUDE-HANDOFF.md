## מגבלות מכוונות של הפיילוט

אין עדיין GPT-Live, אין הקלטת מיקרופון ואין סנכרון ענן. מסכי הקול מסמנים זאת במפורש.
אין עדיין קליטה אוטומטית של שיעור חדש למפת הנושאים של הפיילוט. הספר ממשיך להתעדכן בזרימה הקיימת.

הנתונים ב-`.limba-data` והסודות ב-`.env.local` הם מקומיים ומוחרגים מ-Git. אין למחוק אותם בעת עדכון קוד. אין להעתיק סיסמאות או נתוני לומדים ל-Git.
הנתונים המקומיים משותפים לכל הדפדפנים שמתחברים **לאותו שרת פיתוח**; הם אינם מסונכרנים בין מחשבים או עם Vercel.
שמירה חסומה במכוון ב-Vercel ובמצב production עד שיהיה מסד נתונים מתמשך. אין להחליף את החסימה בכתיבה ל-`/tmp` או באחסון בזיכרון.
מגבלת ניסיונות כניסה היא בזיכרון ומתאימה לפיילוט מקומי בלבד. לפני ענן צריך מגבלה משותפת ומתמשכת, למשל במסד הנתונים.

המשתנה `LIMBA_PERSONAL_HOME=1` מנתב את `/limbaromana.html` ל-`/limba`; הקישור `/limbaromana.html?library=1` ממשיך לפתוח את הספר. המשתנה מופעל בהדגמה המקומית בלבד. ללא המשתנה הכתובת הקיימת ממשיכה כרגיל.
Cookie אישי תקף מתקבל גם בשער הספר הקיים. `LIMBA_GATE=off` הקיים ממשיך לחסום את עמודי הספר.

## נוהל עבודה משותף מחייב לפרויקט הזה

1. בתחילת כל סשן: בדקו מאגר, ענף, commit ו-`git status`. עדכנו refs מהענן והשוו ל-`origin/main` לפני כל שינוי.
2. אם יש עבודה מקומית לא שמורה, שימרו אותה במקומה ועבדו בעותק/ענף נפרד. בלי `reset --hard`, force push, מחיקת stash או העתקת תיקייה שלמה מעל תיקייה קיימת.
3. כל סוכן עובד בענף משלו. שינויי ספר ושינויי ליווי אישי עוברים סקירה לפני שילוב. אין לבצע שני פרסומים מקבילים.
4. לפני שילוב: השוו ל-main העדכני. פתרו קונפליקטים בקובצי המקור ורק אז הריצו מחדש את בונה הספר. אל תבחרו אוטומטית "ours" או "theirs" עבור קבצים שלמים.
5. מיזוג קוד לעולם אינו פעולת איפוס נתוני לימוד. בענן, הנתונים יהיו מחוץ ל-Git עם מיגרציות תוספתיות וגיבוי.
6. בסיום: commit, פרטי ענף ו-SHA, רשימת בדיקות, מצב פרסום ומגבלות בקובץ המסירה. רק main המאושר מתפרסם ל-production.

## הפעלה מקומית

בענף הפיילוט, עם Node ותלויות הפרויקט:

```sh
node scripts/limba/setup-preview.mjs
node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3147
```

סקריפט ההכנה מסרב לדרוס `.env.local` קיים. בעותק הנוכחי הוא כבר הורץ; אין להריץ אותו שוב כדי "לתקן" התחברות.
פרטי הגישה המקומיים נמצאים ב-`limba-local-access.txt`, שאינו מנוהל ב-Git.
כתובת: `http://localhost:3147/limba`.

בדיקות:

```sh
node node_modules/typescript/bin/tsc --project scripts/limba/tsconfig.json
node scripts/limba/check-preview.mjs
node node_modules/eslint/bin/eslint.js src/lib/limba 'src/app/limba/[[...path]]/route.ts' 'src/app/api/limba/[...action]/route.ts' public/limba-personal/app.js scripts/limba/*.mjs src/middleware.ts
```

בדיקת האינטגרציה יוצרת אירוע סינתטי ומסירה רק אותו. אינה מאפסת נתונים קיימים.

## המעבר הבא לענן ולקול

תחילה מסד נתונים עם זהות יציבה, בעלות לכל רשומה והרשאות שמוכתבות מה-session בשרת. החליפו את store המקומי, שימרו מזהי אירועים וגרסאות schema, הוסיפו גיבוי, יצוא, טיפול במיגרציה ומגבלת כניסה מתמשכת. בצעו בדיקות הפרדה גם מול השירות האמיתי.

לאחר מכן חיבור GPT-Live מתוך דפדפן ב-WebRTC עם מפתח OpenAI בצד השרת בלבד. השכבה הקולית תקבל מזהה נושא ותרגול, לא הרשאה להחליף פרופיל שלם. נדרשים ניהול התחלת/סיום שיחה, הרשאת מיקרופון, ניתוק, מגבלת זמן ועלות בצד השרת, בדיקת שמירה לאחר השיחה, וטיפול בכך שתמלול אינו ראיה ודאית להיגוי.

התיעוד שנבדק: https://developers.openai.com/api/docs/guides/voice-webrtc?api=live
יש לאמת מחדש את ממשקי GPT-Live לפני מימוש; לא לחבר אוטומטית API אחר מתוך דוגמה ישנה.

לא להפעיל production על ידי העתקת משתני הסביבה המקומיים. לפני פרסום צריך לבצע בדיקות בנייה מלאות, חיבור למסד, גיבוי ובדיקות פרטיות/הרשאות אמיתיות.

## ממצאי בדיקות ומגבלה קיימת בבניית האתר

הקוד החדש עבר TypeScript ממוקד, ESLint ובדיקות אינטגרציה לחשבונות/שמירה. גם כניסה, תרגול, שמירה ועדכון הדשבורד נבדקו בדפדפן. נתוני הבדיקה הסינתטיים הוסרו, והחשבונות נשארו ללא הישגים מומצאים.

הבנייה המלאה קומפלה, ואז נעצרה בבדיקת טיפוסים קיימת ב-`src/app/blog/map-as-a-lie/geo.ts:29`: החתימה בהגדרות `@types/d3-geo` אינה מקבלת את שני הארגומנטים של `geoMercatorRaw` (וכן `geoEqualEarthRaw`). שורות אלו קיימות ב-base commit ולא שונו כאן. אין לעקוף את TypeScript כדי לפרסם. יש לפתור את התאימות בענף המתאים ולבדוק שוב את האתר המלא לפני מיזוג/פרסום.

לפני הפעלה גלובלית של `LIMBA_PERSONAL_HOME`, יש לבדוק גם קישורים ישנים אל עוגנים ב-`limbaromana.html#...`. הדגל מיועד כרגע לפיילוט בלבד; קישורים ישנים עם hash צריכים להמשיך להגיע לתוכן דרך ניתוב מותאם. הקישורים מתוך הפיילוט כבר משתמשים בכתובות המפוצלות או ב-`?library=1`.
